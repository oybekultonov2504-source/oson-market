# Oson Market

Mobile-first marketplace for Adrasman.

## Production
- Storefront: https://oybekultonov2504-source.github.io/oson-market/
- Admin: https://oybekultonov2504-source.github.io/oson-market/admin.html

## Current versions
- Storefront: **v5**
- Admin: **v10**

## Stack
- HTML / CSS / JavaScript
- Supabase — catalog, advertising, sales and authentication
- Cloudflare R2 — product and advertising images
- GitHub Pages — HTTPS hosting

## Features
- Product catalog and search
- Categories and collections
- Favorites and cart
- Product sheet
- Hero advertising rotation
- Horizontal feed advertising
- Admin panel for products, stock, sales and ads
- Scheduled ads
- Ad on/off control
- Ad image modes: cover / contain
- Optional text overlay on ad artwork

## Image standards
| Content | Ratio |
|---|---|
| Main hero | 16:9 |
| Feed ad | 2:1 |
| Product image | 4:5 |
| Icon | 1:1 |

## Repository rule
This repository is only for **Oson Market**. The Rassvetshop project must not be modified as part of Oson Market work.
